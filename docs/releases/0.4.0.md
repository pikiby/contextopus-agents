# 0.4.0 — Full skill names and discoverable procedures

Agents ships agents, agents-search, agents-edit and agents-settings. Procedures expose operation declarations for discovery through Core. Profiles, teams and main-agent rules remain separate from session communication.

## Installation and compatibility

Use the assets attached to this release and verify their checksums. Modules in this coordinated release require Core 1.7 or later, below 2. Keep persistent data outside source and plugin folders. Use explicit update/upgrade previews for existing roots; client setup does not silently upgrade existing modules.

## Verification and limits

36 tests passed locally. GitHub CI passed on Linux, macOS and Windows with Python 3.12 and 3.13. Tests install the real module through Core and use deterministic embeddings.

Deterministic embedding tests validate retrieval contracts, not real-model ranking quality. Packaging is not proof that every native client version was exercised.
