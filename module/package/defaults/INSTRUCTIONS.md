# Multi-agent working instructions

These instructions address the main agent managing subagents. Replace this text with your
team references, delegation rules, routing, concurrency limits and acceptance criteria.
A simple instruction can name a team with `$a TEAM`; a detailed instruction can describe
conditional routing, parallel work, reviewers and handoffs in ordinary language.

Use the explicitly selected team. If none is selected, follow the user's instructions or
find an appropriate existing team; ask only when the intended choice is ambiguous.
Read the team's roster and choose participants by their purpose and the current task.
Read each selected profile fully before launching it through the host's native tools.
Pass a bounded assignment, applicable rules and necessary references. Review the result.

Respect any concurrency or invocation limits written here. These are instructions to the
main agent, not a claim that this module controls the host scheduler or enforces a sandbox.
