---
name: agents-edit
description: Create or update reusable agent profiles and teams.
---

Reuse the applicable procedure within the task; otherwise obtain and read
`guide(procedure="agents/edit")`. Follow its instruction-reading and action scope. For a
requested native agent creation/update, the main agent chooses and reads the current host's
applicable skills and uses its native tools with the full saved profile. A catalog save alone
does not complete that request. A catalog-only edit does not authorize native changes.
Obtain only unknown signatures with `guide(operation=...)`. Preserve the selected team
and selected host. Profiles/teams are Markdown/YAML sources; use revision-protected tools or authorized file edits, and report broken wikilinks without silently repairing them. If MCP is unavailable, report the connection failure.
